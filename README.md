# Описание проекта

**Simaland** — это крупнейшая оптово-розничная онлайн-платформа, объединяющая десятки тысяч поставщиков и производителей.
Она специализируется на продаже товаров широкого ассортимента, включая категорию «Интерьер» — товары для дома, декора и обустройства помещений.

Simaland предоставляет своим партнёрам и дистрибьюторам различные возможности, включая:

* доступ к каталогу товаров;

* использование готовых карточек товаров для перепродажи на маркетплейсах (Wildberries, Ozon и др.);

Многие партнёры Simaland размещают товары на Wildberries и Ozon, используя предоставленные каталоги.
Однако часть товаров категории «Интерьер» уже продаётся самим Simaland на этих маркетплейсах, что создаёт внутреннюю конкуренцию и снижает прибыльность партнёрских продаж.

**Для анализа данных мы использовали два источника:**

**API Simaland** — для получения актуальной информации о товарах, включая название, категорию, цену и наличие.

**Веб-скрапинг с платформы «Маяк»** — для сбора данных о продажах и наличии товаров на маркетплейсах Wildberries и Ozon.



# Бизнес - задача

**Бизнес-задача проекта:** <br>
Провести анализ и сопоставление данных о товарах категории «Интерьер» и «Праздники» между платформами Simaland, Wildberries и Ozon.<br> <br>

**Основные цели:**
<br>

* Определить ассортимент товаров, которые доступны на Simaland, но не продаются самим поставщиком на Wildberries и Ozon;
* Сформировать список наиболее выгодных позиций для партнёров;
* Повысить прибыльность и устойчивость партнёрских продаж, предоставив аналитические данные для обоснованного выбора товаров для продажи (выделить 600 лучших товаров, чтобы даже начинающие продавцы могли начать торговлю с минимальным ограничением по количеству карточек (600));
